# Rawhide — What's New (Nightlies)

These notes feed the in-app "Update Available" dialog for Rawhide / cutting-edge builds.

## Recent improvements (unreleased — ships in the next build)

- 🗣️ **Twelve languages built in on Linux, and you can add your own** — Spell check on Linux no longer needs anything installed for English, German, French, Spanish, Italian, Dutch, Polish, Russian, Swedish, Portuguese (Brazil and Portugal) or British English — they all ship inside the app. If you already have your own dictionaries installed, those are used first, so words you've taught them still count. Writing in something else? **Settings → Spell Check Language → Load a dictionary file…** takes any hunspell dictionary and adds it permanently. (On Mac and Windows the language list comes from the operating system's own spell checker, so adding a new one there means adding the language in system settings.)

- 🌍 **Pick the language you write in — Settings → Spell Check Language** — If your computer's interface is set to German, Polish, or anything other than English, the chat box was spell checking your English against *that* language's dictionary — underlining most of the words in every sentence. There's now a plain language picker in Settings (with an Off option), and it defaults to English rather than guessing from your system. Set it to whatever you actually chat in. It's on the web/mobile app too, and the two stay in sync. Note this is about your system's *interface language*, not its region/format setting — changing your region to Spain never affected this.

- ✍️ **Spell check now works on Linux — with nothing to install** — Red wavy underlines and right-click "did you mean…" corrections have worked on Mac and Windows for a long time. On Linux they simply never appeared: the app asked the system for spelling help every time you paused typing, and nothing was there to answer. Linux now has its own spell checker built directly into the app, with an English dictionary included — so it just works the moment you launch it, on any distribution, with no packages to install and no extra programs running in the background. Every prose field is covered: the message box, character descriptions, lorebook entries, story prose, all of it. If you already have your own dictionaries installed, the app uses those instead — so other languages keep working, along with any words you've taught them.

- 🧹 **Big internal cleanup: THIRTEEN of the app's most tangled files untangled** — The story reader and dashboard, the Worlds page, the persona page, the group editor, the voice settings window, the Voice & Media settings tab, the image generation options, the model settings window, and the chat appearance window were each one enormous file; all are now clean, small pieces that are far safer to fix and extend. This round the sweep reached deeper: the chat message bubble itself (every reply you see) and the two engines that track bonds, trust and feelings were untangled the same way — with every moved line verified against the original, so nothing about how characters behave changes. The sweep also caught real bugs along the way (two voice-settings dropdowns that clipped long names), and several screens joined the app's warm amber look, dropping stray cool-blue and purple accents. The story reader's book keeps its proper paper-and-leather look in every theme, on purpose.

- 🔊 **Fixed: a spoken message containing a link said "dollar one"** — If a reply included a web link written the markdown way, the voice didn't read the link's name — it literally said "dollar one" in its place. A test written for the voice system's internals caught it; links now speak their label.

- 🤝 **Promises get their own tab in the Journal — and you're the referee now** — No more digging through a wall of memory cards: the character's Journal now has a **Promises** tab listing every commitment, open ones first, each with its status. If the app misses the moment a promise was kept (or broken), press **Mark kept** or **Mark broken** yourself — it applies the same trust and bond effects the automatic detection would have, and writes the milestone. On the web app too, in the chat tools panel. Also fixed underneath: the app no longer re-records a promise it already settled as if it were brand new, which is how one chat ended up with nine copies of the same pledge.

- 🤝 **Promises stop being nagging quest logs** — If a promise was made, the character brought it up practically every turn — and if the app ever missed the moment a promise was actually kept, she'd insist forever that it never happened. Promises now sit quietly in the background the way real ones do: they color the mood right after they're made or resolved, then only resurface occasionally. The app is also better at noticing a promise being kept (it recognizes the promised thing simply *happening*, and watches a longer stretch of conversation). If one is already stuck from before, open the character's diary and delete that promise card.

- 📊 **See exactly what the AI was sent — on desktop AND the web app** — The Context Budget window's "Tap to view full prompt" buttons never actually did anything. Now every section really opens: the system prompt, your persona, the scenario, the Journal, the Realism state — the actual words the model received last turn, in a neat scrollable box with a copy button. Great for answering "why did she say that?" And the web/mobile app gets the same window for the first time, in the chat tools panel.

- 🔌 **The web app now tells you when it can't reach your computer** — Opening the web app with Front Porch AI closed (or the web server off) used to show a normal-looking sign-in page that silently ignored you — the page loads instantly from your device's saved copy, which is a feature, but it never admitted the computer wasn't answering. Now it says so plainly — "make sure the app is open and the web server is on" — with a Try Again button. Signing in mid-outage explains itself too, instead of pretending your password was wrong.

- 🚦 **When the web server can't start, it now helps you fix it** — Instead of a little message that vanished before you could read it, you get a clear explanation in plain words — usually "something else is already using its spot, most likely a second copy of Front Porch AI still running" — and a one-tap **Use port N instead** button that switches to a free spot and tries again for you. No networking knowledge required.

- 💬 **Fixed: a reply could finish as an empty bubble — and stay empty after a refresh** — You'd watch the reply being written, and the moment it finished the bubble went blank, on the web app and desktop alike. The cause: thinking models sometimes rehearse dialogue *inside their private thoughts* ("Jennifer: …"), and the app mistook that rehearsal for the reply ending — cutting the message off mid-thought, which left nothing visible to show. The app no longer cuts a reply while the model is still thinking, rescues replies that still arrive cut, and when a model genuinely spends its whole turn thinking, the bubble now says so — with its thoughts readable under the 💭 flap — instead of showing nothing.

- 📱 **The web app no longer freezes up while the engines think** — On an iPad (or any browser) connected to your computer, long chats could grind to a halt while the Realism Engine and objectives were working. The app was sending the browser far more updates than it could paint — every single word as its own message, and the engine's whole progress log re-sent several times a second — and the browser redrew the entire conversation each time. Updates are now batched and only sent when something actually changed, and the browser redraws only what moved. Long chats on a tablet should stay smooth through the whole turn — and if the connection ever does stall, the app now says so instead of sitting there silently.

- 🌐 **The web server now tells you WHY it couldn't start** — Flipping the web server on could end in a bare "failed to start and was turned off" with nothing to go on. Now the message names the actual problem — usually the port already being taken (a second copy of Front Porch AI still running is the classic), or Windows reserving the port for itself — and tells you what to do about it. A stuck Tailscale can also no longer make the start attempt hang until it gives up.

- 🎭 **Your persona is now per-chat, and the one in Settings is just the starting point** — Picking a persona used to mean two things at once, and they fought each other. Opening an old chat quietly made *that* chat's persona your global one, so the next character you tapped inherited it. And picking a persona from the Persona page could re-stamp whatever chat was still open behind it — sometimes minutes later, when a background save ran. Now there are two separate things: a **default** (Persona page — who new chats start as, and nothing else changes it) and each chat's **own** persona, set when the chat begins and remembered forever after. Opening a chat no longer moves your default, and changing your default no longer touches any existing chat.

- 👤 **Change who you are mid-conversation, on web too** — Tap the avatar beside the message box on desktop, or the new **Persona** button in the chat header on web/mobile, and pick someone else. That's the only thing that changes an existing chat's persona, and it now sticks straight away instead of waiting for your next message. If a persona you were using gets deleted, chats that used it fall back to your default.

- 🎯 **Fixed: correcting one need quietly dragged all the others down** — Telling the Director "she rested on the sofa, energy should have gone up" re-scored *every* need, not just the one you mentioned — and worse, it stacked the new scores on top of the ones already there instead of replacing them. Hygiene could keep dropping further every time you corrected something else entirely, and correcting the same message twice doubled the change. Reprocessing now rebuilds from where the turn started, so running it twice lands in exactly the same place as running it once.

- ✅ **Reprocess only the needs you mean** — The Reprocess Needs window now lets you tick which needs the Director is allowed to touch. Anything you leave unticked keeps the value it already had, instead of being re-rolled against the same scene. Leave everything unticked and it re-scores all seven, exactly as before. On desktop and on the web/mobile UI.

- 📖 **Fixed: Porch Stories was unreachable on a brand-new install** — Stories don't need a character, but the Home screen only offered the Chats/Porch Stories switch once you already had one. On a fresh library you got the "Get started by creating a new character!" panel with no way through to Stories at all — and even if you had somehow flipped the switch, Home would have shown you that same panel again. The switch is now on the empty Home screen too, and choosing Porch Stories takes you straight there, so you can sit down and write a story before creating anybody.
- ✨ **Fixed: a bond's first warming was invisible** — Between "Neutral" and "Receptive" there was a stretch where the relationship label simply didn't change: a bond climbing from nothing up to 14 points still read **Neutral**, because two different tiers shared one word. That first bit of warming — the part you're watching for early on — showed as nothing happening. It now reads **Cordial**, so the ladder has a distinct rung for "there's something here now." Long-term bond had the same gap and got the same fix.
