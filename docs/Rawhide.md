# Rawhide — What's New (Nightlies)

These notes feed the in-app "Update Available" dialog for Rawhide / cutting-edge builds.

## Recent improvements (unreleased — ships in the next build)

- 🎨 **More of the app warmed up** — the Image Studio, avatar gallery, various dialog accents (icons, badges, buttons), and the last cool-blue bits on the chat screen itself (the Fork/Edit-message dialogs, the "responds next" popup, and the little loading spinners) now use the warm porch amber too, so those corners match the rest of the app. (Your chat bubbles stay their familiar look — untouched.)
- 🎨 **The whole app is now warm-porch** — the desktop app's buttons, switches, sliders, tabs and progress bars were still the old cool blue while the chat sidebar and web app had gone warm amber. They now all match the warm porch look across the entire app — right down to the first-run setup screen, the character-creation wizard, the form fields, and the remote-connection screen — so nothing feels out of place anymore. A few colors that *mean* something (the blue "trust went up" chip, the blue "always-on vs. enabled" lorebook markers, live-call status colors) deliberately stay as-is so you can still read them at a glance. (Chat bubbles stay their familiar blue on purpose.)
- 🎨 **Settings got the warm-porch look** — every Settings tab now uses the same warm amber section headings and accents as the chat sidebar, instead of the old cool blue, so the app feels more consistent throughout. (Under the hood the giant Settings screen was also split into small focused files, with no change to how anything works.)
- 👁️ **Vision detection for LM Studio and oMLX is now trustworthy** — the app now asks LM Studio and oMLX directly whether your loaded model can see images (instantly, even before the model finishes loading), instead of guessing from a test request. Vision models no longer get wrongly branded "Vision: none" because the server was still warming up, the test image was too small for the model, or an unrelated error was misread as "can't see" — and on oMLX a text-only model can no longer be wrongly branded as *seeing* (oMLX sometimes accepts images it silently ignores; the app now trusts oMLX's own model type instead). When a check genuinely can't reach the server, you now get "Vision: could not check" with a Retry button instead of a false "none."
- 🧠 **Reasoning models now think on KoboldCpp — every thinking model, not just some** — the "Request Reasoning" switch now genuinely works for local KoboldCpp models. Flip it on and thinking models (Qwen3, the newest Gemma, and more) show their reasoning in a collapsible block under the reply, just like the remote APIs and oMLX; flip it off and they answer straight away. Before, some local thinking models would stay silent no matter what you did — the app wasn't running each model's own built-in template, so its request to "think" was quietly ignored. Now it does, so the switch is honored across the board.
- ⚙️ **The General settings tab is whole again** — the Chat Font picker and the Realism Mode toggles were accidentally replaced with placeholder text in a past cleanup. They're back and working.
- 🖼️ **Your generated images land in the right chat** — if you use /image and switch to another conversation while it renders, the finished picture no longer drops into the wrong chat; you'll get a heads-up to reopen the original chat instead.
- 🎨 **Draw Things won't get stuck anymore** — if a Draw Things image generation times out, the app now cleanly stops it instead of leaving it holding your GPU and jamming the next generation.
- 🛟 **Regenerating an expression pack can't wipe your old one** — replacing a character's expression set now writes all the new images first and only then clears the old ones, so a failure partway through can never leave you with a half-deleted pack.
- ⏱️ **Time keeps flowing in One-Shot mode** — if you use the faster "One-Shot" realism setting, the in-story clock now advances through the day like it always should have (it used to freeze on the starting time). Bonus: last-second personality corrections now stick in One-Shot mode too.
- 👥 **Group chats feel their needs and bonds just like solo chats** — characters in a group now get hungry, tired, and emotionally close on their own personal rhythm, exactly as they do one-on-one. Before, group members could drift out of sync — one character quietly soaking up everyone's mood changes, or getting hungry at the wrong rate. Regenerating, swiping, and deleting messages in a group also no longer nudge a character's feelings the wrong way.
- 🛑 **The "Cancel" button on realism actually cancels now** — hitting cancel while the realism engine is thinking stops the reply cleanly instead of pushing on, and it no longer drops a stray "evaluation interrupted" line into your chat that stuck around forever.
- 🧠 **Smarter memory on capable models** — the Journal and Growth systems no longer get needlessly knocked onto a simpler, more error-prone path just because a model politely said "nothing worth remembering this time" or the server hiccuped for a second.
- 🎭 **Expression packs work on more ComfyUI setups** — generating a full expression set through ComfyUI no longer fails outright when you haven't set up a dedicated edit workflow; it quietly uses the standard path instead.
- 🖼️ **Renaming a character keeps its face** — renaming a character no longer loses its avatar gallery, expressions, and looks (they used to get stranded and the gallery would go blank).
- 📱 **The web app heals itself after your phone sleeps** — when your phone wakes up or the connection blips, the web app now refreshes automatically instead of showing you a frozen, out-of-date chat or library. No more stuck "half-typed" ghost messages either.
- 🛡️ **Your chats are now much harder to lose** — fixed a rare but nasty bug where one hiccup while saving could silently stop *all* chat saving until you restarted the app, and an even rarer one where switching chats at exactly the wrong moment could mix up which chat got saved. Saving is now self-healing.
- 🔁 **Regenerating in group chats no longer skews your characters** — before, every "regenerate" in a group quietly stacked relationship and needs changes on top of the reply you rejected, slowly drifting bonds, moods, and needs. Now a group regen cleanly undoes the rejected reply first — exactly like 1:1 chats always did. Swiping between replies and deleting messages in groups got the same treatment.
- 💾 **Automatic backups are now bulletproof snapshots** — backups are written by the database engine itself instead of copying the file mid-write, so a backup can never be silently broken right when you need it. And restoring a backup from the recovery screen now actually reconnects everything — no more "restart required but nobody told you."
- 🗄️ **Smoother updates and rollbacks** — going back and forth between app versions (say, a nightly and a stable build) can no longer trap you on a "Database Issue Detected" screen when your data was fine all along.
- 💬 **Finding the community just got easier** — the little floating Discord icon in the sidebar is now a proper "Join the Discord" button, sitting right above "Buy Me a Coffee" (on the web app too).
