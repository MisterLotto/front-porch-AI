# Rawhide — What's New (Nightlies)

These notes feed the in-app "Update Available" dialog for Rawhide / cutting-edge builds.
**Only list what landed after the last shipped nightly.** Clear or rewrite this section when a new nightly goes out — do not accumulate history since stable.

## Recent improvements (unreleased — ships in the next build)

*Since nightly `20260811` (`aa66f57` — web eraser).*

- 🎁 **Put things INTO pockets, not just strike them out** — The sidebar's Pockets & Wardrobe (desktop and web) grew a **+**: type "brass key (scuffed)", pick Wearing / Carrying / Set aside, and either **Hand it over** — she accepts it in-scene knowing it came from you — or **Add quietly**, and her next reply is genuinely surprised to find something she can't account for ("how did I end up with this?"). The bookkeeping recognizes the item immediately either way, and the panel now shows even when her pockets are empty so the first item can go in.
- ▶️ **Continue finally counts** — Pressing Continue used to be invisible to the bookkeeping: keys set down, a move to the porch swing, a meal finished, or a climax arriving in the continued text never updated inventory, position, Needs, or Afterglow — ever. The continuation is now scored as new reply text (only the new part, so nothing gets counted twice), chips update to the whole turn, and regenerate/delete still rewind to the turn's true start.
- 🤔 **DeepSeek "thinking" models stopped erroring on effort levels** — Providers quietly re-tier which reasoning efforts a model accepts (DeepSeek v4-flash:thinking now takes only none/high/max). Models with a `:thinking` tag never send low/medium on the wire in the first place (so you do not get a System error on turn one), and any other model still teaches the app from the provider's own 400 once — your setting stays yours.
- 🎚️ **Thinking strength matches the model** — pick a remote model and Settings (and web) ask which thinking levels it actually accepts, then show those chips. Nano-GPT is poked **once**; we remember Kimi 2.6’s menu (and every other) so the next launch does not ask again. If the model cannot turn thinking off, Off is locked.
- 🧳 **Full chat export keeps Realism** — Export as **Full Front Porch** (`.fpchat`) to reimport bond, Needs, swipes, journal, Growth rings, objectives, and story time so fork mid-history still works. **Transcript** is real SillyTavern **JSONL** (dialogue only) for other apps; ST JSONL and old single-JSON dumps both import. Importing an old ST dump no longer steals the open chat’s feelings (bond *or* arousal). Large imports re-embed memory in the background without stalling your next Send. *(Web import/export deferred to a later pass — desktop-first.)*
- ⏪ **Forking an imported transcript rewinds feelings** — SillyTavern dumps carry no Realism snapshots, so a fork starts from the character’s opening bond/time (not the end of the chat). Your Realism/Needs/Objectives switches stay as you set them. In a **group**, each member rewinds to their own last stamp (or card seed if they never stamped), and the story clock follows the nearest stamp in the kept history — not whoever spoke last in the roster.
- 🔐 **Turning on web 2FA needs your password** — a stolen browser session alone can’t enroll a new authenticator or mint recovery codes. Re-enroll while 2FA is already on is refused; turn it off first (that still needs password + code).
- 🛡️ **First web login setup is local-first** — creating the web account from another phone, LAN, or tunnel needs a one-time code from desktop **Settings → Web Server**. Same computer on localhost still works without a code.
- 🌐 **Turning on Tailscale/ngrok needs your web password** — a stolen browser session alone can’t publish a public or tailnet URL to your whole app.
- 🧠 **Memory (RAG) sidebar got real setup feedback** — Settings say what they do (“past moments per reply”), and if the local model isn’t there you get Download / a progress bar / a real error + Retry — not a dead “Model not downloaded” dot. Web tools mirror the status (download still runs on the desktop host).
- 🎒 **Belongings get their own Journal tab** — Placement notes (“I set my jacket down by the hot tub”) live under Journal → **Belongings** next to Promises / Our Story (count badge included). Same surface on the web tools sidebar. The diary section for these cards no longer crashes the editor.
- 📍 **"Where we are" forgets discarded scenes** — Regen or delete clears a stale story recap until the Journal rewrites it from the real timeline (better empty than wrong).
- 🧹 **Eraser clears the diary note too** — Striking an item off with ✕ also drops its Belongings memory, so “where are my keys?” doesn’t keep claiming a placement you deleted.
- ⏪ **Group gifts and diary cards rewind cleanly** — Handing Sam the keys then regenerating restores **both** inventories (no phantom gift). Placement cards from a rejected “keys on the table” reply are purged with the rewrite.
- 🔁 **Thinking models stop replaying prior plans** — Hidden reasoning stays in the collapsible thinking view only, on every generation path (including overflow / Continue). Continue is plain transcript + partial again — no leftover journal/world state blocks fighting the line.
- 🚀 **Long chats keep a stable history window** — Once old messages scroll out of context, they stay out, so local backends (oMLX, KoboldCpp, LM Studio) can actually use their prompt cache. Very deep @depth lore stays near recent turns so it doesn’t thrash that prefix.
- 📅 **Memory day stamps work with Realism off** — When Passage of Time runs alone, retrieved memories still get a story-day stamp so old words don’t read like they just happened.
- 📖 **Web Journal is real** — Plant, edit, pin, retire memory cards from the tools sidebar; optional “review before it applies” with Apply/Discard (same as desktop Growth).
- 🔞 **Web can flip 18+ themes** — The master switch lives in Porch Life so After Dark and intimate editor fields stay reachable (or hidden) without needing desktop.
- ✨ **Output Sanitizer on web Settings** — Find/replace rules for model output, same host-side sanitizer the desktop Generation tab drives.
- 🌍 **Stoop on web shows Living Worlds** — Browse / mine / downloads / creator lists include places, matching desktop.
- 🧠 **Memory receipts tell the truth** — When the engine is down or errors after older messages scrolled out, the sidebar no longer pretends “no lookup needed.”
- 🗑️ **Deleting a chat cleans everything** — RAG embeddings, quests, Living Worlds links, and biome spans leave with the chat; Database Cleanup also sweeps growth rings and dead-chat quests.
- ☀️ **Light mode: Main Settings is readable again** — Menu items and the button label use theme ink (not pure white on paper). Chat Settings dialog matches the warm light surfaces of UI / Model / TTS settings.
