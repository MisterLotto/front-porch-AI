# Rawhide — What's New (Nightlies)

These notes feed the in-app "Update Available" dialog for Rawhide / cutting-edge builds.

## Recent improvements (unreleased — ships in the next build)

- 🎤 **Bring your own Piper voice.** Community-made and self-trained Piper voices now work in Front Porch — not just the official catalog. Grab any Piper voice (the standard `.onnx` + `.onnx.json` pair — hundreds are on Hugging Face, or train your own on your own recordings), open the Voice Model Browser, hit **Add custom voice**, and pick the file. Front Porch converts it on the spot — fully offline, in about a second — and it shows up in the voice picker like any other voice, assignable per character. If a file isn't a standard Piper voice, you get a plain-English explanation instead of a silent failure. (Requested on Discord — thanks!)

- 🪞 **One character editor everywhere — full toolkit in-chat, and it finally respects light mode.** Editing a character from inside a chat used to open a stripped-down copy of the editor: no Realism section, no Ambitions, no token count — and some of its changes saved the instant you touched them, so Cancel didn't really cancel. Now the chat's "Edit Character" opens the same full editor the library uses, in a dialog over your conversation, and nothing is saved until you hit Save. Your edits reach the live chat immediately on save. (Bubble and text colors are in the UI Settings dialog, where the Themes update put them.) The editor also joined the warm-porch design language: if you use light mode, character editing is finally light too — everywhere it opens.
- 🧹 **Output Sanitizer — replace words and phrases the model keeps getting wrong.** Set up find-and-replace rules that clean up the AI's replies before they're saved to your chat history — on every backend, local or remote. Turn on the sanitizer in Chat Settings, add rules with exact text or limited regex patterns, and optionally apply them retroactively to existing chats (your own messages are never touched, and you'll be asked to confirm first). Stop sequences and banned phrases editors have been refreshed too.
- 🐛 **Per-chat generation settings no longer bleed between chats.** Opening chat B after chat A could silently leave B running on A's per-chat generation overrides (temperature, stop sequences, sanitizer rules, etc.) — including brand-new chats, which could even save A's overrides as their own. Every path into a chat now loads (or clears to) the right settings.
- ⚡ **Control whether the backend auto-starts when you open a chat.** The local backend previously started every time you entered a conversation. You can now turn this off in Settings → Backend ("Auto-start on chat open") — useful when you're just reading old messages or don't want the overhead of loading a local LLM. The toggle is on by default, so existing behavior is unchanged.
